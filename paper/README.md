# JOSS paper package

Create `paper.md`, `paper.bib`, and figures only after maintainers provide author
approval, affiliations, funding, software-use publications/preprints, and verified
real-data workflow evidence. Paper must describe software, not new biological
results. Include Summary, Statement of Need, State of the Field, Software Design,
Research Impact, Acknowledgements, References, and AI usage disclosure.

Do not submit before public development history satisfies JOSS requirements.
